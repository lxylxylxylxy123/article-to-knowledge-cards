# 金融材料学习教练

一个独立的中文金融入门 Skill。将用户提供的教材、文章或视频文字稿转化为可逐步学习的小课：识别重点与前置知识、解释概念和常见误区、用生活例子和练习检验理解。它不依赖脚本、第三方包或 API；联网核验和文件读取取决于运行环境的能力。

## 文件结构

```text
finance-material-coach/
├── README.md
├── skills/finance-material-coach/
│   ├── SKILL.md
│   └── agents/openai.yaml
└── examples/
    └── validation.md
```

## 安装

将 `skills/finance-material-coach` 整个文件夹复制到 Codex 识别的个人 Skills 目录（常见路径为 `~/.codex/skills/finance-material-coach`），保留目录结构。重新打开会话或刷新 Skills 列表，然后通过 `$finance-material-coach` 调用。不同宿主的安装路径和刷新方式可能不同，请按该环境说明操作。已有同名目录时先比较内容，不要覆盖自己的改动。

## 使用示例

把材料粘贴在提示后，或提供运行环境可读取的文件/链接：

```text
使用 $finance-material-coach 帮我学习以下教材段落。我是零基础，先指出最重要的知识、需要补的前置概念和常见误区，再用生活案例解释，并出一道题让我自己回答：

存款本金 1000 元，一年利率 3%，一年后取回本息；当年物价上涨 5%，忽略税费。
```

也可以说“给我答案并解释”“继续上一节，先复习一道题”或“只讲我不懂的债券收益率”。如果只有视频链接而没有可访问字幕，Skill 会说明无法看到的内容并请求文字稿，而不会伪造内容。进度仅基于当前会话或你提供的学习记录。

输出区分【原文】【教学补充】【推断】；这些标签说明内容来源类型，不自动证明原文真实。实际利率、法规、产品和具体投资决策等需要按地区及日期核实。Skill 用于学习，不保证模型每次输出完全正确，请复核关键计算与来源。

`examples/validation.md` 收录三组自编材料、独立模拟结果和可核对的数值，用于复现检查；它们不是教材引文，也不代表真实用户已经掌握。
